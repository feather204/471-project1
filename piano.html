Summary

The piano component is built around 88 piano samples, representing the standard piano keys. When a note is started by the Sequencer, the PianoInstrument plays the correct note and generates audio one frame at a time.

When the Synthesizer reads a note from the score, it registers the notes duration, velocity and pitch, then prepares the WAV file for playback. When samples are first loaded, the implementation stores them in a cache, saving the program from having to re-open the same WAV file.

Implemented Features:

  • All 88 standard piano keys.
  • Polyphony: Notes can be played simultaneously.
  • Envelope: Notes fade out after their duration.
  • Sustain Pedal: Notes continue when the pedal is down, fading out when lifted.
  • Velocity: Notes have a velocity that impacts volume.
  • Pedal Noise: A sample is played when the pedal is used.
