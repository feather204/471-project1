Score File Formatting:

The following is an example of the score file format:

    <score bpm="110" beatspermeasure="4">
        <instrument instrument="PianoInstrument">
            <note measure="1" beat="1" duration="1" note="E4" velocity="0.78" />
        </instrument>
    </score>

There are also two special notes representing the pedal functions of the piano:

    <note measure="1" beat="1" duration="0" note="PedalDown" velocity="1" />
    <note measure="2" beat="1" duration="0" note="PedalUp" velocity="1" />

Attributes for the score format:

  • bpm: Beats per minute.
  • beatspermeasure: Number of beats in a measure.
  • instrument: Type of instrument used.
  • measure: Measure in which the note begins.
  • beat: Beat in which the note begins.
  • duration: Length of the note.
  • note: Name of the note to use.
  • velocity: The volume the key is pressed at.
